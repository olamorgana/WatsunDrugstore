## 📋 PROJECT OVERVIEW
 
Watsun Drugstore is an e-commerce web application. The application features a product catalog, shopping cart with 6% SST tax calculation, user registration and login, order management, and an admin dashboard with sales reporting.
 
### Tech Stack
- **Framework:** ASP.NET Core MVC (Empty Template)
- **Language:** C# 12.0
- **Database:** SQL Server (LocalDB)
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Tools:** Microsoft Visual Studio 2026
  
### Key Features
✅ Product catalog with search and category filter  
✅ Shopping cart (session-based)  
✅ Checkout with 6% SST tax calculation  
✅ User registration & login (Customer & Admin)  
✅ Order confirmation and receipt  
✅ Customer order history  
✅ Admin dashboard with statistics  
✅ Admin sales reporting (detailed & executive summary)  
✅ Role-based page authorization  
✅ Input validation (server & client-side)

## 🚀 QUICK START
 
### Installation Steps
 
#### Step 1: Clone the Repository
1. Open Visual Studio
2. Click **File** → **Clone repository**
3. Paste repository URL:
   ```
   https://github.com/YourUsername/WatsunDrugstore.git
   ```
4. Choose folder location
5. Click **Clone**
 
#### Step 2: Create Database
 
1. In Visual Studio, create App_Data folder and copy file path
3. Go to **Tools** → **SQL Server Object Explorer**
4. Right-click on **(LocalDB)** → **New Database**
5. Name it: `WatsunDB`
6. Location: **paste file path here** 
7. Right-click database → **New Query**
8. Open and execute **SQLQuery1.sql** file (in project root)
9. Wait for all tables and sample data to be created
   
#### Step 3: Build Solution
 
1. In Visual Studio: **Build** → **Build Solution** (or press Ctrl+Shift+B)
2. Wait for build to complete
3. Check for any errors in Error List
